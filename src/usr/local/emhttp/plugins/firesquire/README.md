**FireSquire**

Pre-reboot health check for Unraid: a single GO / CAUTION / NO-GO verdict before you reboot, so you never reboot into a known landmine.

Advisory only: it reads the host and reports. Its one write is an empty test file on the flash, which it deletes right away. Adds a button next to Reboot on the Main tab, a flame icon next to Reboot on the Dashboard and a page under Settings → User Utilities.

**FireSquire**

Pre-reboot health check for Unraid: a single verdict (All clear, Smouldering or The roof is on fire) before you reboot, so you never reboot into a known landmine.

Advisory only: it reads the host and reports. On the flash it writes an empty test file, which it deletes right away, the CRC error count and the SMART values of each disk, so it notices when one rises, and 30 days of the Health tab's lights. A Health tab shows how the server stands, and Stop on Main checks what holds the array. Adds a button next to Reboot on the Main tab, a flame icon next to Reboot on the Dashboard and a page under Settings → User Utilities.
